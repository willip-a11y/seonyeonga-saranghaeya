# 선영아 사랑해야 ♡

4050 여성을 위한 익명 온라인 커뮤니티의 **실시간 웹사이트 체험 버전 3(MVP)** 입니다.
온라인 절 '산사'의 여유로운 분위기에서 아이디어를 얻었지만, 그래픽과 코드는 새로 만든 독립적인 디자인입니다.

## 실행하기

1. [Node.js 20 이상](https://nodejs.org/)을 설치합니다.
2. 이 폴더에서 터미널을 열고 다음 명령을 입력합니다.

   ```bash
   npm start
   ```

3. 인터넷 브라우저에서 `http://localhost:3000`에 접속합니다.
4. 같은 와이파이에 있는 다른 기기에서는 `http://<서버의-내부-IP>:3000`로 접속해 함께 테스트할 수 있습니다. 인터넷 전체에 공개하려면 Node.js를 실행할 수 있는 호스팅 서비스에 배포하고 도메인을 연결해야 합니다.

**npm install이 필요 없습니다.** Node.js 내장 HTTP + Server-Sent Events(SSE)로 실시간 동기화됩니다.

## 방별 기능

- **1번 ㄴㅁ 인사방:** 인원 100명 제한(서버에서 검사), 모든 접속자 닉네임은 `ㄴㅁ`, 보내는 문구도 `ㄴㅁ` 하나뿐입니다.
- **2번 마음껏 수다방:** 닉네임 `ㄴㅁ`, 한 번에 200자까지 자유 채팅, 성시경·은지원·소지섭·강동원·서강준·공유 등 6인의 팬아트풍 수채화 초상이 둥둥 떠다니는 배경. 소개 문구는 **“우리들의 이야기”**.
- **3번 다이어트방:** 입장 시 목표 몸무게 입력 필수, 본인에게만 표시, 입장 순서대로 12초씩 운동하고 스쿼트·런닝머신 버튼을 누를 때마다 캐릭터가 동작하며 자기 횟수가 1씩 올라갑니다. 굶기 버튼을 누르면 「忍 · 나는 배부르다」 연출이 2.2초마다 반복되며 다시 누르면 중지합니다. 운동과 인사·응원은 실시간으로 다른 접속자에게 전파됩니다. 실제 굶기를 권하는 기능이 아닌 유머 연출입니다.
- **공통:** 로그인 없음, 라이브 인원수, **바닥을 눌러 캐릭터 이동 및 다른 방문자에게 위치 공유**, 아바타 표시, 모바일 화면 지원, 방별 공유 링크, 접속 종료 시 자동 퇴장. 대화는 최근 60개만 메모리에 임시 보관.

## 사진과 배경

산사 웹사이트의 그래픽/배경을 그대로 가져오지 않았습니다. 원본과 비슷한 숲속 사찰의 느낌을 독창적인 CSS 일러스트로 표현했습니다.

2번 방에는 **별도로 생성한 수채화 스타일 팬아트 이미지 6개**를 사이트에 포함했습니다. 인물 모습은 예술적으로 재구성한 일러스트이며 실제 사진이 아닙니다. 공개 서비스는 특정 연예인이 이 커뮤니티에 참여하거나 후원하는 것으로 오인되지 않도록 별도 안내를 해야 합니다. 사진으로 교체하려면 각 사진의 사용 조건 및 초상권을 확인하세요.

## 운영 시 고려할 점

이 버전은 소규모 **테스트/MVP** 입니다.

- 동시 접속자 100명 제한은 **1번 방의 이 서버 인스턴스 안에서만** 정확히 적용됩니다. 여러 서버로 확장하려면 Redis 등 공유 상태 저장소가 필요합니다.
- 가입/로그인이 없어 악성 이용자 추적이 어렵습니다. 공개 배포 전 신고·차단·관리자 기능, 더 강화된 스팸 차단과 콘텐츠 관리가 필요합니다.
- 대화 내용은 데이터베이스에 저장하지 않으며 서버를 재시작하면 사라집니다. 서버에서 최근 60개를 메모리에 보관합니다.
- 목표 몸무게는 해당 방문의 메모리에만 저장하고 다른 사용자에게 보내지 않습니다. 연결이 끝나면 삭제됩니다.
- 실제 사람 접속과 실시간 동기화는 웹 서버에서 실행해야 작동합니다. HTML 파일만 열면 **미리보기 모드**로 작동하며 사용자 수나 실시간 대화가 연결되지는 않습니다.
- 운영 규모, 사용량에 따라 서버 비용과 관리 비용이 발생합니다.

## 배포

Node 20+를 지원하는 호스팅 서비스에서 시작 명령을 `npm start`로 설정하고, `PORT` 환경변수를 호스팅에서 주는 값으로 사용하면 됩니다. SSE 트래픽이 차단되지 않아야 하고 이 버전은 서버 프로세스 하나에서 운영하도록 되어 있습니다.

## 바로 놀기

- `선영아_사랑해야_혼자놀기.html` 파일을 열면 설치 없이 **3개 방 모두 입장해서 실제로 버튼을 누르고 체험**할 수 있습니다. 이 파일에서는 다른 실제 이용자와 연결되지 않습니다.
- **다른 사람과 같이 놀기**: `npm start` 후 같은 서버 주소에 여러 브라우저에서 접속합니다. 입장·인사·채팅·위치 이동·응원이 다른 사람에게 실시간 표시됩니다.
- 2번 방은 사진처럼 보이지만 실제 사진이 아닌 수채화 **팬아트 스타일 일러스트**입니다.
